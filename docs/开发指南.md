## 目录职责

| 路径 | 职责 |
| --- | --- |
| `frontend/src` | 界面、样式、API 客户端；不保存数据库凭据 |
| `frontend/vite.config.ts` | 本地 API 代理和固定端口 |
| `backend/app/config.py` | 从根目录 `.env` 与环境变量读取 PostgreSQL 配置 |
| `backend/app/db.py` | 连接池、连接/查询超时、请求级 Session |
| `backend/app/models.py` | 基础模型；金额和净值使用 Numeric/Decimal |
| `backend/app/main.py` | 健康检查、路由和响应错误处理 |
| `backend/app/funds.py` | 基金目录、详情、净值、自选和更新日志接口 |
| `backend/app/sources.py` / `sync_funds.py` | 共用来源解析、增量 / 全量同步、校验与证据日志 |
| `backend/app/seed.py` | 可重复的历史样本导入，不覆盖已有基金 |
| `backend/migrations` | 版本化表结构；应用启动不自动建表 |
| `backend/tests` | 配置、接口和 PostgreSQL 集成验证 |

## 数据库基础表

| 表 | 当前字段与约束 |
| --- | --- |
| `users` | UUID、唯一邮箱、密码哈希、带时区创建时间；兼容旧邮箱字段；新增规范化唯一用户名及认证接口 |
| `simulation_accounts` | 一用户一账户、Decimal 可用余额、非负约束；注册事务写入 100,000.00，并写入唯一初始本金流水 |
| `funds` | 六位代码、名称、类别、来源 URL/时间、样本标记、交易开关默认关闭 |
| `fund_navs` | 基金代码和日期联合主键、正数单位/累计净值，最多 8 位小数 |
| `watchlists` | 用户与基金联合主键，防重复添加；已开放基于会话归属的幂等添加 / 取消 |
| `alembic_version` | 数据库迁移版本 |

用户账户和自选均有外键。已增加买入订单、持仓批次和在途资金，见 [模拟买入与确认结算](模拟买入与确认结算.md)。注册使用规范化用户名及加盐密码哈希，在同一事务内创建用户、账户、本金流水及首次会话。旧基础用户保留邮箱并赋予 legacy_ 前缀内部用户名，不自动为旧数据补发资金。

## 迁移与样本

先按 README 创建 Conda 环境和 `.env`，在仓库根目录运行：

```powershell
conda run -n simulate-alipay python -m alembic -c backend/alembic.ini upgrade head
conda run -n simulate-alipay python -m alembic -c backend/alembic.ini current
conda run -n simulate-alipay python -m alembic -c backend/alembic.ini check
```

修改模型后生成迁移，再人工检查生成脚本，特别是删除列/表和默认值：

```powershell
conda run -n simulate-alipay python -m alembic -c backend/alembic.ini revision --autogenerate -m describe_change
```

已发布的迁移不要直接改写，新增后续迁移。不要在有业务数据的数据库上随意执行 `downgrade`，首个版本的回滚会删除这些基础表。需要回滚演练时使用单独的临时数据库。

可选样本导入：在根目录运行 `conda run -n simulate-alipay --cwd backend python -m app.seed`。从仓库内固定快照导入 5 只基金，每只 3 行净值；排除 QDII，保留来源时间，交易保持关闭。重复导入跳过已有基金及其净值，避免覆盖后续同步；不以种子脚本修复不完整的业务数据。

## 接口约定

| 接口 | 行为 |
| --- | --- |
| `GET /api/health/live` | 进程存活，无须数据库 |
| `GET /api/health/ready` | 检查连接及 Alembic 版本，未就绪返回 503 |
| `GET /api/funds?q=&page=1&page_size=20` | 名称/代码、分类、自选过滤；多种排序；返回总数和分页；每页上限 100 |

净值 JSON 使用十进制字符串，避免后端转浮点导致精度丢失。前端只在展示时格式化，不做交易计算。数据库错误返回通用 503，不暴露驱动错误和凭据。基金和健康检查仍公开只读；账户接口从服务端会话确定归属，写接口要求来源校验头。当前仅绑定本机，限流按单进程实现。

## 常见启动问题

- 页面提示服务未就绪：检查后端终端、PostgreSQL 服务、根目录 `.env`，再执行 `upgrade head`。修复后点击“重新检查”。
- 8000 或 5173 已占用：先检查已有进程，使用已启动实例或正常关闭对应项目服务；不要批量结束其他程序。
- 旧 Conda / 新 PowerShell：统一使用 `conda run`，避免激活 hook 的空参数兼容问题；不需要执行 `conda init`。
- 依赖安装失败：确认 `conda run -n simulate-alipay python --version` 正常且对该环境有写权限；使用 `--no-user` 防止退回全局用户安装。前端使用项目内忽略的 npm 缓存。
