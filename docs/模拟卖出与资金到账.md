## 规则范围

仅开放 000147 易方达高等级信用债债券 A。规则版本 `000147-redemption-sim-v1`，模拟生效期 2026-09-17 至 2026-12-31；需要跨入未核验的 2027 年到账日期时拒绝新单。其他基金保持浏览、自选范围。

依据[基金公司 2026 年 1 月更新招募说明书](https://cdn.efunds.com.cn/owch/data/bulletin/20260131/易方达高等级信用债债券型证券投资基金更新的招募说明书.pdf)正文第 3–4、26–32 页和[上交所 2026 年休市安排](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)：

- 0.01 份起赎，最多两位小数。按先确认先赎回分配批次；排除已冻结及未到可赎回日的份额。买入通常 T+1 确认、T+2 起可赎回。
- 持有天数按自然日，从买入确认日至预计赎回确认日计算，不含赎回确认当日。
- 赎回费率：少于 7 天 1.50%；7–29 天 0.75%；30–364 天 0.10%；365–729 天 0.05%；730 天起为 0。
- 每批赎回金额 = 份额 × 正式 T 日单位净值；每批费用 = 该批赎回金额 × 费率；净到账为各批扣费金额之和。金额使用 Decimal，四舍五入到分。末次清仓结转该批剩余全部成本，避免舍入残留。
- 本练习室约定北京时间交易日 15:00 截止、截止前可撤单，T+1 起确认、T+7 到账。T+n 排除周末及交易所休市日。公开文件规定通常 T+7 内支付；**固定 T+7 是模拟约定，不代表支付宝渠道实际到账时间**。

试算使用最近保存的正式净值，并显示日期；确认只使用对应 T 日正式净值。没有该日净值、最近同步失败或冲突时继续等待，不能用旧净值代替成交。当前无实时暂停公告及渠道折扣接入。

## 份额、资金与收益

| 操作 | 份额 | 资金 |
| --- | --- | --- |
| 提交 | 冻结各批分配份额，仍计入持仓 | 不增加现金 |
| 撤单 | 释放冻结份额，不收赎回费 | 不变 |
| 确认 | 减少剩余份额及冻结份额，结转成本 | 增加扣费后赎回在途 |
| 到账 | 不变 | 赎回在途转入可用现金 |

总资产 = 可用现金 + 买入在途 + 剩余持仓市值（含冻结份额）+ 赎回在途。持仓净值收益 = 市值 − 剩余成本；已实现收益 = 已确认赎回净额 − 结转成本；累计净值收益 = 总资产 − 初始本金。成本包含申购费，赎回净额扣除赎回费。

当前未实现分红、份额拆分与再投资权益。检测到持仓期间未处理事件时，停止新赎回及相关待确认赎回，并隐藏可能误导的累计/持仓收益；市值仍为已保存份额乘净值的估算。已确认的赎回款不因之后的净值同步失败而停止到账。未被数据源识别的事件不在本阶段保证范围内。

## 接口与事务

- `GET /api/redemptions/context/{code}`：本账户可赎回、冻结份额与日期。
- `POST /api/redemptions/quote`：分批试算及绑定日期、净值、持仓、费率的 `quote_token`。
- `POST /api/redemptions`：提交份额、原试算 token 和 UUID 请求编号。状态变化要求重新试算；同账户同请求编号重放返回原单，不重复冻结。
- `GET /api/redemptions/{id}`：订单详情；`POST .../cancel` 撤销；`POST .../refresh` 检查确认和到账。
- `GET /api/orders`：合并买卖记录，支持 `kind=all|buy|sell`、状态与分页。
- 账户、持仓及流水返回新增赎回在途数据。所有私有接口由会话确定归属，不接受客户端指定账户；他人的订单返回 404。

所有写操作先锁账户，再在需要时锁基金；创建订单和冻结、确认和成本结转、到账和流水分别在同一事务内完成。流水事件键唯一，重复请求及并发结算不会重复到账。买入时也保留当时的赎回在途余额快照。

API 启动及每 60 秒尝试结算，重启后补处理。工作进程只读取本地数据库，不自动抓取净值；仍需按已有同步工具更新基金数据。超过 7 天未同步时不接受新赎回。

先执行 `python -m alembic -c backend/alembic.ini upgrade head`，再重启 API。迁移 `d8be352ddbad` 新增卖出订单、分配批次、冻结与剩余份额、赎回在途及流水字段；原有持仓从原份额/成本回填，不重复发放本金。存在卖出订单时禁止降级删除其审计记录。
