# 多基金模拟交易与自动同步

## 支持范围

应用从东方财富公开目录同步全市场基金代码、名称和类型，不绑定基金公司，也不需要支付宝账号。2026-09-20 实测目录为 **27,883 只**，数量随来源变化。这个目录不等于支付宝当前在售清单；无法保证支付宝全部产品、实时申赎状态或渠道优惠费率均被覆盖。

| 产品 | 数据与模拟行为 |
| --- | --- |
| 000147 | 保留原公开标准费率模拟方案；原订单快照不变，新的 v2 方案移除年度到期限制，仍须存在已公布交易日历 |
| 普通境内股票、混合、债券、指数及 ETF 联接基金 | 正式净值同步成功后自动开放通用模拟买卖；申购费假定为 0，赎回不足 7 天 1.5%、满 7 天 0；这不是基金合同或支付宝实际费率 |
| QDII、FOF、REIT、定开、持有期、封闭、养老、境外币种等特殊产品 | 导入目录；非货币产品可同步公开单位净值；专用交易模型未实现，不开放模拟买卖 |
| 货币基金 | 仅目录展示；尚未接入万份收益、七日年化及收益结转模型，不把万份收益误当单位净值 |

通用方案为 1 元起购，15:00 北京时间截止，T+1 起等待正式 T 日净值确认、赎回 T+7 到账，金额/份额保留两位，赎回按 FIFO。买入和卖出均保存所属基金的规则快照，试算过期、跨基金规则版本、重复提交和并发超额申请仍受校验。缺失正式计价日净值不使用其他日期替代。

## 升级运行

在仓库根目录执行迁移，然后启动或重启后端：

```powershell
conda run -n simulate-alipay python -m alembic -c backend/alembic.ini upgrade head
conda run -n simulate-alipay --no-capture-output --cwd backend python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

后端启动即检查目录和日历，每日更新。无需另外创建系统计划任务。发现页显示目录总数、已同步净值数量、24 小时内更新数量和异常数量；输入六位代码可排队更新，基金详情也有当前基金更新入口。手动更新需要登录，每只基金有 5 分钟冷却。

## 定时策略与恢复

- 持仓、自选及在途基金在北京时间 **08:00、20:00、23:00** 进入优先同步队列，补偿净值晚发布的情况。手动请求优先级最高。
- 其余净值型基金按上次同步时间轮询，目标为每天一轮；每批 20 只，整个进程请求间隔至少 1 秒。全市场有数万只基金，首次同步及限流期间可能超过一天，页面计数反映实际进度，不能承诺上游数据定点全部到齐。
- 每只净值型基金首次同步补齐最近约 400 天，再标记成功；来源历史不足 400 天时获取全部可用历史。此前仅同步一页的基金在下次轮询或手动更新时自动补齐，无需清空数据库。之后增量同步并重叠校验近 14 天；完整成立以来历史可使用 `--full`。近一年涨跌要求存在一年前的有效基准，成立不足一年或来源缺失基准时仍显示横线。
- 网络或格式错误 15 分钟后重试；目录和日历失败保留缓存。净值修订保留旧值与冲突记录并暂停自动重试该冲突，需核验后手动更新。已保存资金和订单不受覆盖。
- 数据库会话锁阻止多个 API worker 同时运行同步批次；逐基金事务锁防止同步与结算交错。任务记录持久化，进程重启后继续处理，运行中断的任务在 15 分钟后回收。
- 自动同步依赖后端和数据库持续运行。关机/停止服务期间不更新，重启后补处理。需要全天候更新应把同一后端部署为常驻服务；本次未创建操作系统后台服务。

## 交易日历

内置上交所已公布的 2025、2026 年休市日期；每日从[上交所年度休市安排](https://www.sse.com.cn/disclosure/dealinstruc/closed/)解析并缓存后续公布年份。年度日历必须包含完整节假日和合法日期，调休周末仍不交易。2025 年来源为[上交所年度公告](https://www.sse.com.cn/disclosure/announcement/general/c/c_20241223_10767108.shtml)。

缓存位于 `data/calendars/<year>.json`，经校验后原子替换；跨年确认/到账逐日查相应年份。未公布或未同步年份明确暂停试算，不把普通工作日假设为交易日。QDII 等境外日历尚未实现。

## 命令行与接口

```powershell
# 立即更新目录和已公布日历
conda run -n simulate-alipay --cwd backend python -m app.sync_funds --catalog --calendar

# 任意目录内净值型基金，补最近约 400 天
conda run -n simulate-alipay --cwd backend python -m app.sync_funds --codes 000001 161725

# 指定基金成立以来完整历史
conda run -n simulate-alipay --cwd backend python -m app.sync_funds --codes 161725 --full

# 全市场同步（耗时较长，日常使用后台轮询即可）
conda run -n simulate-alipay --cwd backend python -m app.sync_funds --all

# 000147 保持显式启用；其他支持通用方案的基金同步后自动启用
conda run -n simulate-alipay --cwd backend python -m app.enable_trading --code 000147
```

`GET /api/data/coverage` 返回覆盖率与目录/日历任务状态；`GET /api/data/update?code=000001` 查询单基金任务；登录后 `POST /api/data/update?code=000001` 排队更新。未传 code 的旧客户端兼容默认 000147。

原五只易方达基金保留官网净值交叉核对；其他基金明确标记为公开净值单一来源。分红/拆分注记不会因同步而清除；未核验事件会阻止相关收益展示及赎回。通用来源尚未自动补齐分红登记日、除息日和发放日，不能把净值下跌自动判定为现金分红。

## 验证

新增测试覆盖双基金买入与结算、独立赎回和余额、不同基金规则快照、跨年与未知年份、目录导入幂等、非易方达净值同步、调度优先级与失败重试。真实来源抽查 000001、161725 均返回 2026-09-18 最新净值，年度日历解析返回 2026 年完整休市安排。
